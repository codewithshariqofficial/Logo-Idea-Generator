# Logo Idea Generator

A simple web app that generates logo concept ideas based on a brand name, style, and count.

## What's Inside

- `index.html` — Main page with the form and results layout
- `style.css` — All styling (dark theme, glassmorphism, animations)
- `script.js` — Logo generation logic and UI interactions

## Features

- Enter a brand name or keywords
- Choose a logo style: Modern, Retro, Minimal, Playful, Luxury
- Choose how many logos to generate: 6, 10, 15, 20, 30, or 50
- Each logo shows an icon, name, description, and color palette
- Copy logo details to clipboard
- Responsive design (works on mobile and desktop)

## How to Run

No installation needed. Just open `index.html` in any web browser.

## Tech Used

- HTML
- CSS
- JavaScript
- Google Fonts (Inter)
- Font Awesome icons

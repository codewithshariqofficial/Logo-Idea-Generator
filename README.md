## About

A **creative logo idea generator** that generates random logo concepts, color combinations, and design inspiration with a single click. Perfect for designers looking for quick inspiration.

Built with **vanilla HTML, CSS, and JavaScript** -- simple and fun to use.

---

## Features

| Feature | Description |
|---------|-------------|
| Random Ideas | Generate random logo concepts |
| Color Combos | Random color palettes |
| One Click | Generate with single button click |
| Copy Ideas | Save your favorite ideas |
| Clean UI | Modern minimalist design |
| Responsive | Works on all devices |
| Fast | Instant generation |
| Fun to Use | Addictive random outputs |

# Logo Idea Generator

A front-end web app that generates logo concept ideas — icon, name, description, and color palette — from a brand name, a chosen style, and a count. No build tools, no backend: just open `index.html` in a browser.

## ✨ Features

- Enter a brand name or keywords to base the concepts on
- Choose a logo style: **Modern**, **Retro**, **Minimal**, **Playful**, **Luxury**
- Choose how many logos to generate: 6, 10, 15, 20, 30, or 50
- Each generated card shows:
  - An icon
  - A generated logo name
  - A short description
  - A 4-color palette with swatches (with hex tooltips)
- **Copy** button to copy logo details (name, icon, colors) to the clipboard
- **Save** button on each card
- Responsive layout for mobile and desktop
- Dark glassmorphism UI with animated background shapes and smooth card animations

## 🛠 Tech Stack

- **HTML5** — structure and markup
- **CSS3** — styling, glassmorphism, animations, responsive design
- **Vanilla JavaScript** — generation logic and DOM interactions
- **Google Fonts** (Inter) — typography
- **Font Awesome 6.4.0** — icons (via CDN)

## 🚀 Getting Started

No installation or build step is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/codewithshariqofficial/Logo-Idea-Generator.git
   ```
2. Open `index.html` in any modern web browser.

That's it — the app runs entirely in the browser.
